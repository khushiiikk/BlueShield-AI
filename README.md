**🌊 BlueShield-AI**
AI-powered flood forecasting system leveraging atmospheric and hydrological data for early warning and disaster resilience.

**📌 Overview**
BlueShield AI integrates advanced feature engineering, ensemble learning (Random Forest), and spatial hydrology data to predict:

🌧️ **Flood Severity Levels**
None, Above Normal, Severe, Extreme

⚠️ **Flood Occurrence:** Binary classification – Yes / No

Trained on over 4,500 real flood events and enriched with 100+ geographic features, the model achieves:

**✅ >99% accuracy**

✅ NSE (Nash-Sutcliffe Efficiency): 0.9993
Making it an exceptional early-warning and risk-assessment tool.

**🧠 Core Features**

🚨 Predict flood occurrence using historical precipitation and hydrological data

🔍 Classify flood severity with near-perfect precision

📊 Leverages spatial and temporal precipitation trends

🛰️ Processes catchment characteristics, gauge metadata, and weather sequences

🔁 Includes cross-validation and model comparisons

🧪 Evaluates performance with metrics like MSE, RMSE, F1-score, and NSE
